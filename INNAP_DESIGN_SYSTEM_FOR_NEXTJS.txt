1. PROJECT OVERVIEW
================================================================================

Name:            Innap — Hotel Admin Dashboard
Type:            Full-screen admin panel (NOT a marketing landing page)
Layout:          Fixed left sidebar + fixed top header + scrollable content
Framework (old): HTML + Bootstrap 5 + jQuery + Chart.js / ApexCharts
Target rebuild:  Next.js (App Router) + React + Tailwind (recommended)
Viewport:        Full browser width/height (100% / 100vh shell)
Default theme:   Light, vertical layout, full sidebar, fixed header/sidebar

Default settings (from js/deznav-init.js):
  typography:       "poppins"   (charts use Poppins; CSS body uses Roboto)
  version:          "light"
  layout:           "vertical"
  primary:          "color_1"   → #1362FC
  headerBg:         "color_1"   → #FCFCFC (light chrome)
  navheaderBg:      "color_1"   → #FCFCFC
  sidebarBg:        "color_1"   → #FCFCFC
  sidebarStyle:     "full"
  sidebarPosition:  "fixed"
  headerPosition:   "fixed"
  containerLayout:  "full"      → edge-to-edge (full screen)

Core hotel pages to rebuild first:
  - Dashboard Light          → index.html
  - Dashboard Dark           → index-2.html
  - Guest List               → guest-list.html

5. FULL-SCREEN LAYOUT (CRITICAL — MATCH THIS STRUCTURE)
================================================================================

Shell structure (full viewport):

  #main-wrapper          → full app shell, opacity fade-in on load
  ├── .nav-header        → logo area (top-left of sidebar)
  ├── .header            → top bar (search, notifications, profile)
  ├── .deznav            → left sidebar navigation
  ├── .content-body      → main scrollable page content
  │   └── .container-fluid
  ├── .footer            → copyright bar
  └── .chatbox           → right slide-over chat panel (optional)

Desktop default dimensions:
  Sidebar (.deznav / .nav-header) width:  20.5rem  (328px)
  Header height:                          6.5rem   (104px)
  Header left padding (clears sidebar):   20.563rem
  Content margin-left:                    20.563rem
  Sidebar top offset:                     6.5rem (sits under nav-header)
  Sidebar height:                         calc(100% - 6.4375rem)
  Footer padding-left:                    17.1875rem (aligns under content)

≤1400px (87.5rem) adjustments:
  Sidebar width:   17rem
  Header height:   5.5rem
  Content margin:  17.2rem
  Nav-header height: 5.6rem

≤1024px-ish / tablet:
  Header height: ~5.6rem
  Sidebar collapses toward mini / overlay behavior

≤767px (mobile):
  Sidebar: overlay drawer (~18rem)
  Nav-header width collapses; brand title hidden at ≤1023px (63.9375rem → width 5rem)
  dashboard_bar hidden
  Content full width

Layout behavior for Next.js:
  - Use CSS Grid or fixed sidebar + margin content (same numbers).
  - html, body, #__next / layout root: height 100%, overflow-x hidden.
  - Sidebar + header: position fixed.
  - Main content: margin-left = sidebar width; padding-top = header height when fixed.
  - data-container="full" → full-bleed (no boxed max-width shell).
  - This is a FULL SCREEN admin app, not a centered marketing page.
